🌸 Suffix cheat sheet

Remember: the ending can tell you what kind of word you are looking for.

-er / -or

person/thing that does something
teach → teacher

-ee

person who receives an action
employ → employee

-ist

person involved in an activity/belief
violin → violinist

-tion / -sion

verb → noun
admit → admission

-ness

adjective → noun
happy → happiness

-able / -ible

can be done
read → readable

-ment

often forms nouns
enjoy → enjoyment

-ity

state/quality noun
scarce → scarcity

-hood

state/condition
child → childhood

-ship

relationship/status
friend → friendship

-ive

often an adjective
produce → productive

-ous

adjective, often “full of/characterized by”
danger → dangerous

-ful

adjective, “full of”
care → careful

-less

adjective, “without”
harm → harmless

-ify

makes a verb
pure → purify

-ise / -ize

adjective → verb
modern → modernise

💡 Nadu's golden trick

-ER = DOER → teacher, worker, employer

-EE = RECEIVER → employee, trainee, payee

-ABLE = CAN BE DONE → readable, countable, forgivable

-NESS / -ITY = QUALITY OR STATE → happiness, scarcity, flexibility
